# dashboard-recursos-humanos
Proyecto de análisis de datos de Recursos Humanos con SQL Server, Excel y Power BI. Incluye consultas SQL, KPIs, visualizaciones y conclusiones del análisis.

## Objetivo

Analizar información de empleados para obtener indicadores relevantes sobre la distribución de personal, salarios, formación académica, cargos, horas extras, rotación y rangos de edad.

## Herramientas utilizadas

- SQL Server
- Excel
- Power BI
- GitHub

Las consultas SQL se utilizaron para explorar y transformar los datos antes de construir los dashboards.
